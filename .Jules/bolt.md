## 2024-03-24 - Debouncing Global DOM Queries in MutationObserver
**Learning:** Using `MutationObserver` to globally watch for DOM node additions and blindly calling O(N) operations like `document.querySelectorAll` inside the callback can cause severe layout thrashing and performance degradation, especially during React micro-mutations which might trigger the observer multiple times per frame.
**Action:** When performing heavy operations like `document.querySelectorAll` within a `MutationObserver` on a large subtree (like `document.body`), always debounce the callback using `requestAnimationFrame`. This ensures the O(N) DOM query runs at most once per animation frame, significantly reducing main thread blocking time. When doing this in strict mode, type the `rafId` as `number | undefined` and check before clearing.
