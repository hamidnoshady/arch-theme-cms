## 2023-10-26 - Debouncing MutationObserver in React with requestAnimationFrame
**Learning:** When using `MutationObserver` on `document.body` in a React application, React's frequent micro-mutations can trigger the observer callback multiple times per frame. If the callback performs heavy DOM traversals (like `querySelectorAll`), this synchronous execution causes severe layout thrashing and O(N) performance degradation. Also, when implementing debouncing with `requestAnimationFrame` in TypeScript, explicitly type the frame ID as `number | undefined` and guard `cancelAnimationFrame` to prevent TS2454 (used before assignment) errors during strict type checking.
**Action:** Always debounce global DOM traversal callbacks triggered by `MutationObserver` using `requestAnimationFrame` to ensure the heavy query only runs once per render frame. Ensure proper `undefined` checks on the frame ID variable in TypeScript before cancellation.
