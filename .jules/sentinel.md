## 2025-02-23 - URL Control Character Bypass
**Vulnerability:** URLs containing ASCII C0 control characters (like `\u0001`) or DEL could bypass standard URL validation logic. When processing links (e.g., `javascript:alert(1)`), `String.prototype.trim()` does not remove these control characters. Subsequent regex checks looking for protocol strings (like `/^(https?:|mailto:)/`) would fail, but the catch-all logic intended for relative paths would accept the string as "safe", allowing it to bypass the filter and reach the DOM.
**Learning:** Browsers silently ignore certain control characters in URLs (such as `\u0001` or `\t`), so `\u0001javascript:alert(1)` executes successfully in the browser even if it evades standard scheme validation logic in code.
**Prevention:** When writing URL validators, specifically block strings containing C0 control characters and DEL (`[\u0000-\u001f\u007f]`) before validating the scheme. Ensure this is performed after `.trim()` so valid trailing/leading whitespace doesn't trigger the block.
